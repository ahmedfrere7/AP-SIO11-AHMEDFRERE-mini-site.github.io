Ligne de commande Linux : mémento

Ce mémento regroupe les commandes Linux utiles en SISR, classées par thème. Pour chaque commande : son rôle et un ou plusieurs exemples d'utilisation. Pour tout savoir sur une commande, tapez man commande dans le terminal.

Navigation et gestion des fichiers

Navigation et gestion des fichiers : commandes, descriptions et exemples
Commande Description Exemple d'utilisation
pwd Affiche le répertoire courant pwd
ls Liste les fichiers et dossiers ls -l
ls -la
cd Change de répertoire cd /home/user
cd ..
cd ~
mkdir Crée un dossier mkdir projet
mkdir -p site/css/img
rmdir Supprime un dossier vide rmdir dossier_vide
touch Crée un fichier vide (ou met à jour sa date) touch index.html
cp Copie un fichier ou un dossier cp a.txt b.txt
cp -r site site_sauvegarde
mv Déplace ou renomme un fichier ou un dossier mv ancien.txt nouveau.txt
mv fichier.txt /tmp
rm Supprime des fichiers ou des dossiers (définitif, pas de corbeille) rm fichier.txt
rm -r dossier

Lecture, recherche et édition de fichiers

Lecture, recherche et édition de fichiers : commandes, descriptions et exemples
Commande Description Exemple d'utilisation
cat Affiche le contenu d'un fichier cat /etc/hostname
less Affiche un fichier page par page (q pour quitter) less /var/log/syslog
head Affiche les premières lignes d'un fichier head -n 5 fichier.txt
tail Affiche les dernières lignes d'un fichier (-f : suit les ajouts) tail -n 20 fichier.log
tail -f /var/log/syslog
nano Édite un fichier dans le terminal nano fichier.txt
echo Affiche un texte ou l'écrit dans un fichier avec > echo "Bonjour"
echo "texte" > fichier.txt
grep Recherche un motif dans un fichier grep -i "erreur" fichier.log
grep -r "TODO" .
find Recherche des fichiers dans une arborescence find /home -name "*.html"
wc Compte les lignes, mots et caractères wc -l fichier.txt

Utilisateurs, groupes et droits

Utilisateurs, groupes et droits : commandes, descriptions et exemples
Commande Description Exemple d'utilisation
whoami Affiche le nom de l'utilisateur courant whoami
id Affiche l'identifiant et les groupes de l'utilisateur id
sudo Exécute une commande avec les droits administrateur sudo apt update
su Change d'utilisateur su - alice
useradd Crée un utilisateur (-m : crée son dossier personnel) sudo useradd -m alice
passwd Définit ou change un mot de passe sudo passwd alice
usermod Modifie un utilisateur (ex. l'ajouter à un groupe) sudo usermod -aG sudo alice
userdel Supprime un utilisateur (-r : supprime aussi son dossier) sudo userdel -r alice
groupadd Crée un groupe sudo groupadd sio
chmod Modifie les droits d'un fichier (lecture, écriture, exécution) chmod 755 script.sh
chmod u+x script.sh
chown Change le propriétaire et le groupe d'un fichier sudo chown alice:sio fichier.txt

Système, processus et aide

Système, processus et aide : commandes, descriptions et exemples
Commande Description Exemple d'utilisation
man Affiche le manuel d'une commande man ls
history Affiche l'historique des commandes saisies history
clear Efface l'écran du terminal clear
uname Affiche des informations sur le système et le noyau uname -a
hostname Affiche ou modifie le nom de la machine hostname
date Affiche la date et l'heure date
uptime Affiche depuis quand la machine est allumée uptime
df Affiche l'espace disque des partitions df -h
du Affiche la taille d'un dossier du -sh /var/log
free Affiche l'utilisation de la mémoire free -h
ps Liste les processus en cours ps aux
top Affiche les processus en temps réel (q pour quitter) top
kill Arrête un processus à partir de son PID kill 1234
kill -9 1234
systemctl Gère les services (démarrer, arrêter, état) systemctl status ssh
sudo systemctl restart ssh
journalctl Affiche les journaux du système journalctl -xe
shutdown Éteint ou redémarre la machine sudo shutdown -h now
sudo reboot

Gestion des paquets (Debian / Ubuntu)

Gestion des paquets (Debian / Ubuntu) : commandes, descriptions et exemples
Commande Description Exemple d'utilisation
apt update Met à jour la liste des paquets disponibles sudo apt update
apt upgrade Met à jour les paquets installés sudo apt upgrade
apt install Installe un paquet sudo apt install apache2
apt remove Désinstalle un paquet sudo apt remove apache2
apt search Recherche un paquet apt search nginx
dpkg -l Liste les paquets installés dpkg -l | grep apache

Réseau

Réseau : commandes, descriptions et exemples
Commande Description Exemple d'utilisation
ip a Affiche les interfaces réseau et leurs adresses IP ip a
ping Teste la communication avec une machine ping -c 4 8.8.8.8
ss Affiche les ports en écoute et les connexions ss -tuln
traceroute Affiche le chemin suivi par les paquets jusqu'à une machine traceroute example.com
nslookup Interroge le DNS pour obtenir l'adresse IP d'un nom nslookup example.com
curl Envoie une requête HTTP et affiche la réponse curl -I https://example.com
wget Télécharge un fichier depuis le web wget https://example.com/fichier.zip
ssh Se connecte à une machine distante en ligne de commande ssh alice@192.168.1.10
scp Copie un fichier vers une machine distante via SSH scp fichier.txt alice@192.168.1.10:/tmp

Archives et compression

Archives et compression : commandes, descriptions et exemples
Commande Description Exemple d'utilisation
tar Crée (-c) ou extrait (-x) une archive .tar.gz tar -czvf archive.tar.gz dossier
tar -xzvf archive.tar.gz
zip Crée une archive .zip zip -r site.zip site
unzip Extrait une archive .zip unzip site.zip

Attention : rm supprime définitivement et sudo donne les droits administrateur. Vérifiez toujours une commande avant de l'exécuter.
